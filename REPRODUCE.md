# Reproduction Guide

**Version 0.1.0** · 2026-11-12 · Scaffold / not a completed demo

## What can be reproduced now

Clone the hub and component repositories at the commits recorded in project-package.json. Inspect the project brief, fictional CSV files, app/report contracts and employee definitions. Recalculate fixture totals. These are source scaffolds; there is no running app/report/container yet.

## Required finished-project instructions

1. Verify release manifest, file hashes, component commits and image digests.
2. Install documented supported runtime/report tooling; confirm recipient Power Apps/Power BI tenant and license requirements.
3. Configure recipient-owned credentials outside Git.
4. Import the packaged data into the selected documented storage and configure app/report connections.
5. Import/build the app and report from their included source/export files.
6. Configure employees with their pinned role definitions, actual provider/model/effort and approved repository clones.
7. Reconcile initial totals and department filters against independent expected values.
8. Submit a request, confirm one saved record, approve/reject it and refresh the report using the documented method.
9. Test invalid inputs, failed saves, empty states and failure/recovery. Record exact versions, actual results and unperformed cases.
10. Retain a fresh-workspace run record and walkthrough before declaring a reproducible release.

These steps are the delivery checklist, not completed installation instructions. Each implementation step must gain exact commands/screens, required accounts, expected outputs and troubleshooting during the build.
