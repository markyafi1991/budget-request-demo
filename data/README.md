# Synthetic Data

**Version 1.0** · 2026-11-12

All rows are invented for this project; no client extract was used. Currency units are demonstration USD. Month is YYYY-MM. budgets.csv has one row per month/department; requests.csv has one row per RequestId. AlreadySpent excludes all listed request amounts. Approved requests are reserved amounts, not claimed booked accounting actuals.

Initial totals: budget 95000; already spent 73500; approved requests 4400; pending requests 1200; available budget 17100. Pending/Rejected requests do not reduce available budget. See the pinned report contract for department cases and the Sales approval transition.
